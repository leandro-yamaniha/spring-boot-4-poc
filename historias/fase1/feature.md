# Feature – Fase 1 – MVP Core de Pedidos

A Fase 1 tem como foco o **core de pedidos**:

- Criação de pedidos por clientes para lojas.
- Visualização e acompanhamento de pedidos pelas lojas.
- Fluxo básico de status do pedido (criado → em preparo → em rota → entregue/cancelado).

## Histórias de Usuário da Fase 1

1. **HIST-000 – Criação do scaffold do backend**  
   "Como desenvolvedor, quero criar o scaffold do backend Java/Spring Boot para que o time possa implementar as funcionalidades de pedidos de forma organizada e consistente com as diretrizes do projeto."

2. **HIST-001 – Criação de pedido**  
   "Como cliente, quero criar um pedido para comprar produtos de uma loja."

3. **HIST-002 – Visualização de pedidos pela loja**  
   "Como loja, quero visualizar os pedidos recebidos em tempo quase real para poder atendê-los rapidamente."

Estas histórias são detalhadas em arquivos separados nesta pasta, com tasks técnicas associadas a cada uma.
